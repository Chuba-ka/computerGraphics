# Локальные шрифты

Установите Times New Roman или положите свои полные файлы `times.ttf`
и `timesbd.ttf` в эту папку. Файлы `.ttf` исключены из Git.
Встроенные в образец PDF шрифты содержат только часть символов, поэтому
не используются как шрифты общего шаблона.

Текущий отчёт не использует курсив. Если он понадобится, добавьте также
`timesi.ttf` и `timesbi.ttf`; без них курсивное начертание локального шрифта
заменяется обычным. При отсутствии локальных файлов шаблон ищет установленный
Times New Roman, затем Liberation Serif, сообщая о замене в журнале сборки.
