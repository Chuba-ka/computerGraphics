# Отчёты в LaTeX

Общий шаблон оформления и содержание конкретной работы хранятся отдельно.
Текст лабораторной № 1 перенесён из исправленного DOCX и дополнен краткой
математической частью и двумя скриншотами приложения. Список литературы
и ссылки на удалённую литературу не добавляются.

## Структура

```text
latex/
├── main.tex                  точка входа LaTeX
├── build.sh                  короткая команда сборки
├── config/
│   ├── report.tex            выбор активной работы
│   └── identity.tex          вуз, автор, группа, преподаватель, город и год
├── labs/
│   └── lab_01/
│       ├── metadata.tex      номер работы, курс, тема и вариант
│       ├── content.tex       порядок разделов этой работы
│       ├── assets/screenshots/ изображения этой работы
│       └── sections/
│           ├── 01-condition.tex
│           ├── 02-method.tex
│           ├── 03-results.tex
│           ├── 04-conclusion.tex
│           ├── method/       отдельный файл для каждого подраздела
│           └── results/      примеры работы со скриншотами
├── template/
│   ├── preamble.tex          подключение общих настроек и пакетов
│   ├── titlepage.tex         титульный лист
│   └── settings/
│       ├── fonts.tex         шрифты
│       ├── layout.tex        формат листа и поля
│       ├── text.tex          размер текста, интервалы и абзацы
│       ├── headings.tex      заголовки и нумерация разделов
│       ├── math.tex          формулы и интервалы вокруг них
│       ├── figures.tex       изображения и подписи
│       └── pages.tex         номера страниц
├── resources/
│   └── fonts/                собственные файлы шрифтов, если нужны
├── scripts/
│   └── build.sh              логика сборки
├── tools/                    локальный компилятор
└── build/                    всё, что создаётся при сборке
    ├── pdf/                  итоговые PDF
    ├── work/                 служебные файлы, журнал и промежуточный PDF
    └── cache/                кэш TeX-пакетов
```

В Git входят исходники, настройки, скрипты, документация и скриншоты. Папка `build`,
локальный исполняемый файл Tectonic и файлы шрифтов исключены из Git.

## Редактирование

Содержание меняйте в `labs/lab_01/sections/`. Порядок разделов задаётся в
`labs/lab_01/content.tex`, подразделов метода — в `sections/02-method.tex`.
Реквизиты текущей работы находятся в `labs/lab_01/metadata.tex`, общие
титульные данные — в `config/identity.tex`. В `config/report.tex` выбирается
папка активной работы. Для обычного редактирования отчёта менять `main.tex`
или общие настройки не нужно.

Пишите русский текст в UTF-8. Пустая строка начинает новый абзац.
Заголовки задаются через `\section{Название}` и `\subsection{Название}`;
номера и оформление добавляются автоматически. Не выравнивайте текст
пробелами и не добавляйте `\\` в конце обычных абзацев. Специальные символы
экранируются: `\_`, `\%`, `\&`, `\#`. Имена файлов можно писать через
`\path{tetrahedron_test.cpp}`.

Новый подраздел подключается в файле раздела:

```tex
\input{\ReportRoot/sections/method/05-new-topic}
```

Формулы находятся рядом с пояснениями в подразделах геометрии и проекции.
Для нумерованной формулы используйте `\begin{equation} ... \end{equation}`,
для короткой формулы внутри текста — `\( ... \)`.
Изображения текущей работы хранятся в `labs/lab_01/assets/screenshots/`,
их подключение и подписи — в `sections/results/01-screenshots.tex`.
Подписи имеют вид «Рисунок 1 — Название»; ссылки задаются через `\label` и `\ref`.

## Сборка

Из корня проекта:

```bash
./reports/latex/build.sh
```

Результат: `reports/latex/build/pdf/308_Храмов_Лаб1.pdf`.
Команда работает и из другой директории. Исходные DOCX и PDF рядом с папкой
`latex` автоматически не заменяются. После проверки можно самостоятельно
скопировать результат в папку `reports`.

На текущем компьютере подготовлен локальный Tectonic в `tools/tectonic`
и кэш пакетов в `build/cache`. Скрипт находит компилятор автоматически.
На другом компьютере нужен Tectonic либо TeX Live с XeLaTeX. Для Ubuntu/Debian:

```bash
sudo apt install texlive-xetex texlive-lang-cyrillic texlive-latex-extra latexmk fonts-liberation
```

Tectonic при первой сборке загружает пакеты из сети. При отсутствии Tectonic
скрипт использует `latexmk` с XeLaTeX либо два запуска XeLaTeX. Для компилятора
вне PATH задайте `TECTONIC=/путь/к/tectonic` перед командой сборки.

## Следующая лабораторная

1. Скопируйте `labs/lab_01` в `labs/lab_02`.
2. В `config/report.tex` замените `labs/lab_01` на `labs/lab_02`.
3. Измените `labs/lab_02/metadata.tex` и текст её разделов.
4. Соберите с новым именем PDF:

```bash
./reports/latex/build.sh 308_Храмов_Лаб2.pdf
```

Подключения используют общий путь `\ReportRoot`, поэтому менять его внутри
каждого подраздела не требуется. Отчёт первой работы остаётся в своей папке.
Всю папку `latex` можно перенести в другой проект. В Overleaf загрузите
исходные файлы с сохранением структуры, выберите `main.tex` и XeLaTeX;
локальные инструменты, кэш и результаты сборки загружать не нужно.

## Оформление

Основные параметры взяты из исправленного образца: А4, поля 30/15/20/20 мм,
основной текст 14 пт, полуторный интервал, абзац 1,25 см, выравнивание по ширине
без промежутков между абзацами. Заголовки полужирные, того же размера,
с абзацным отступом и автоматическими номерами. Переносы слов отключены.
Номер страницы расположен снизу по центру; титул учитывается, но его номер
скрыт. Разделы идут подряд. `\clearpage` начинает новый лист; в текущем отчёте
он используется перед выводами.

Это адаптация оформления под лабораторную и пользовательский образец,
а не гарантия полного нормоконтроля по ГОСТ. Приоритет имеет Times New Roman;
если его нет, используется Liberation Serif с предупреждением. Для точного
совпадения шрифта с образцом установите полный Times New Roman либо положите
свои файлы в `resources/fonts` под именами `times.ttf`, `timesbd.ttf`,
`timesi.ttf`, `timesbi.ttf`. Для текущего отчёта достаточно первых двух;
подробности — в `resources/fonts/README.md`. Встроенные в PDF подмножества
символов не подходят для произвольных новых текстов. Переносы строк и страниц
могут отличаться от Word даже при одинаковых размерах и полях.
