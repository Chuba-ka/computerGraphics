# Локальный компилятор

Здесь может находиться исполняемый файл `tectonic`. Скрипт сборки использует
его, если Tectonic не найден в PATH и переменная `TECTONIC` не задана.

Компилятор подготовлен на текущем компьютере, но сам исполняемый файл
исключён из Git. Для другой системы установите Tectonic или XeLaTeX;
сборка не привязана к локальному двоичному файлу. Кэш пакетов находится
в `../build/cache`, результаты — в `../build/pdf`.
